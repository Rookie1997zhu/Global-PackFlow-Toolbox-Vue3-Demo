02｜P0 核心工具详细需求

01 集装箱装柜优化器

输入：20GP/40GP/40HQ 或自定义内尺寸、有效载重、多个 SKU 的长宽高/重量/数量、可旋转方向、可堆叠约束。

计算：按体积或最长边排序，结合空余空间分割等启发式算法生成可行装载布局；检查箱体边界、碰撞、总重量和数量。

输出：已装/未装数量、体积利用率、重量占比、2D 俯视/侧视、Three.js 3D 预览、JSON/CSV/图片导出。

验收：无重叠、无越界、重量不超限；旋转限制生效；无法装入时明确提示。算法结果仅称“可行方案”，不承诺全局最优，也不替代重心与货物固定安全审查。

02 纸板材料排版优化器

输入：板材宽高、边距、切割间隙、多规格矩形、数量、旋转许可。

计算：实现 MaxRects 或 Guillotine 算法，提供至少两种排版策略，支持多张板材。

输出：SVG 排版图、利用率、废料面积、张数、各规格完成数量、SVG/CSV 导出。

验收：矩形不重叠、不超边界；数量与面积统计准确；相同输入产生可重复结果。异形 Nesting 和共边切割不纳入 V1.1。

03 CBM / 体积重计算器

输入：多行尺寸、件数、单件重量、单位（mm/cm/m/in、kg/lb）、用户可设体积重除数及进位规则。

输出：单行及合计 CBM、实际重量、体积重量、计费重量、CSV 导入导出。

验收：单位转换一致；数量为零、负值、空值、极端数值正确提示；计费重量规则可配置且结果可追溯。

04 物流运费比较器

输入：快递/空运/海运自定义报价，最低收费、计费进位、固定费、百分比附加费、币种及预计时效。

输出：各方案费用明细、总价、排序、差额、CSV/PDF 摘要。

验收：不同计费规则独立配置；清晰标识“用户输入的模拟报价”，不得展示为实时承运商价格。

06｜验收标准与风险边界

  • 计算准确：正常、边界、异常数据均有测试用例；公式及单位口径可检查。
  • 可视化可信：装柜和排版不得出现明显碰撞、越界或数量不符。
  • 导出可用：CSV、XLSX、PDF、SVG 等输出需检查内容、编码、尺寸和布局。
  • 多语言完整：工具标题、字段、错误提示、按钮、导出模板保持中英韩一致。
  • 纯前端可运行：无后端 API 时所有本版核心功能仍可使用。
  • 性能可控：复杂计算提供进度、取消或超时提示；大数据计算使用 Worker。
  • 专业边界明确：装柜算法不保证全局最优，材料排版不等同于生产刀模认证，运费为用户输入模拟值。
发布建议：先完成 Sprint 1 的共享校验和导出规范，再开发两个复杂优化工具。不要为了快速增加功能而跳过计算正确性验证。

07｜最终目标

V1.1 发布后，PackFlow Tools 应当成为一个可独立输入、实时计算、可视化查看、比较结果、导出文件的纯前端专业工具 Demo 集合。保留当前网站整体风格，不加入真实支付与账号系统，也不强制各工具串联使用。

后续 V1.2：依据用户反馈再考虑批量计算、复杂约束、工具收藏、方案保存和已有刀版 CAD / 卡板优化 Demo 的正式集成。
